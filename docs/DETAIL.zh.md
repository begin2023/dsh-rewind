# 会话回溯

用户消息下提供「编辑」，助手回复下提供「重新生成」。编辑时可以修改正文、选择保留或移除已有附件，以及追加图片与文件。原样提交可以重新发送该问题。

修改后，当前模型上下文保留该位置之前的消息，再从修改后的输入继续。原问题、旧回答及后续消息退出当前上下文；历史事件通过 DSH Session Surface 的替换标记保留。编辑替换标记上的「放回输入框」可以恢复原始用户输入及附件。

图片仍以图片内容提交，文件仍以附件内容提交。原始文件需要仍存在于本机附件存储中。

重新生成不会撤销文件修改、命令或外部服务操作。插件不读取模型密钥，不直接覆盖会话文件，也不启动独立网页服务。安装或升级后请重启 DSH。插件界面当前使用中文。

使用方法、兼容性和开发说明见 [中文 README](../README.md)。
